# ADR-001：控制器基座选型

- 状态：生效（现行实现）
- 日期：2026-09-08 起（初始化补记于 2026-09-09）

## 背景

需要复刻 Remielle 的原生控制器行为，且要在 Unity 中可操作、可验证。

## 决策

控制器基座 = **原生复刻层（`ControllerRuntime` 的 Native* 系列，按取证链逐环复刻状态图/过渡/混合/姿态/时钟）+ 接入层（`ControllerIntegration`）**，位移/碰撞用 OpenKCC，状态机库用 UnityHFSM，相机用 Cinemachine 3.1.7。全部内嵌主工程，不依赖外部包管理。

## 后果

- 行为规格有取证链背书，出错可回归证据解读原版。
- 已支持移动/闪避/冲刺/普攻/特殊技/输入缓冲/命中链。
- 已知表达力缺口（如 walk→fly 的二段移动）在现行状态机内待验证；若确认受限，进入 ADR-004 级别的新基座评估（见 `40_Integration/Controller/Candidates`），不推倒重来。
