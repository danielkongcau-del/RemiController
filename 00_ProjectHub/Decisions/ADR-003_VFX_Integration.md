# ADR-003：特效接入策略

- 状态：生效
- 日期：2026-09-08~09（初始化补记于 2026-09-09）

## 决策

特效按"**逐项取证 → GPU 组装 → 真机生命周期验证**"接入：每一项先读原始粒子系统/材质/贴图/时钟规则，再组装，再以 30/60/120 Hz 真实 Player 帧验证（实例预热、无临时创建、打断回收）。对照以同帧 GPU 画面为准，不以离线截图或加亮灯光替代。HDR 问题按诊断链定位（当前：相机未挂最终 LUT、高亮饱和未校准）。

## 后果

- 接入速度受取证约束，但每项可追溯、可回归。
- 闪光颜色类问题必须走 HDR 诊断链，不允许直接调色凑近。
