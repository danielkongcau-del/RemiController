# 展示／商店辅助消费者：来源与适用范围

本次没有重新抓游戏。使用原来的两页抓帧、原始像素 shader 汇编、资源指针和 GPU 输出，核实了深度／法线辅助层的去向。

反射像素 shader 为 70f3eedc1f8cc637。它的 t5 正是辅助层的法线／采样编号，t6 正是交错深度。两对关系都通过同一捕获内的实际 D3D11 resource 指针和完整 DDS 载荷验证，未用文件名中的资源哈希冒充对象身份。

shader 从辅助层 alpha 恢复全分辨率采样位置，读取角色分类。当前 UI 角色的 R10 alpha 为 3/3，也就是 1。原始末尾比较和条件选择明确将这一分类的反射 RGB 置零。

## 验证结果

- 两页共 238,352 个半分辨率采样点选中角色分类。
- 两张实际反射输出为 R11G11B10_FLOAT，共 1,674,432 个打包数据字，全部为零。
- 环境处理先写入另一个 HDR 目标，再恢复角色分支。完成后共 7,706,528 个角色区域的半精度分量与处理前逐位一致。没有把尚未恢复角色的中间绘制误判为最终画面。
- 在记录的角色绘制至后处理区间中，线性深度未见后续采样使用；深度范围仅进入下一层归并。完整资源访问行保存在报告中。

因此，当前纯角色展示场景可以保留角色 HDR，不必为得到这两页的角色外观实现无贡献的环境反射。实时深度辅助层仍逐帧生成；不是用静态截图替代，也不是把环境反射强加给角色。
